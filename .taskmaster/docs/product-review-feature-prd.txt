# Product Review System - Product Requirements Document (PRD)

## 프로젝트 개요
Ultra Shopping Mall의 제품 상세 페이지에 완전한 고객 리뷰 시스템을 구현합니다.

## 목표
1. 고객이 구매한 제품에 대해 별점과 텍스트 리뷰를 작성할 수 있게 함
2. 리뷰에 최대 5장의 이미지를 첨부할 수 있게 함
3. 다른 고객들이 작성된 리뷰를 쉽게 탐색하고 필터링할 수 있게 함
4. 제품의 평균 별점과 리뷰 통계를 명확히 표시함

## 핵심 기능 요구사항

### 1. 리뷰 작성 기능
- 로그인한 사용자만 리뷰 작성 가능
- 구매한 제품에 대해서만 리뷰 작성 가능 (구매 검증)
- 제품당 1개의 리뷰만 작성 가능 (중복 방지)
- 리뷰 작성 폼:
  * 별점 선택 (1-5점, 필수)
  * 텍스트 리뷰 (선택, 최소 10자 이상 권장)
  * 이미지 첨부 (선택, 최대 5장, 각 5MB 이하)
- 실시간 입력 검증 및 피드백

### 2. 리뷰 이미지 업로드
- 이미지 파일 형식: JPG, PNG, WebP
- 파일 크기 제한: 개별 5MB, 총 25MB
- 드래그 앤 드롭 지원
- 업로드 전 미리보기 기능
- 이미지 최적화 (리사이징, 압축)
- 클라우드 스토리지 또는 로컬 public 폴더에 저장

### 3. 리뷰 표시 및 UI
- 평균 별점 표시 (소수점 1자리)
- 총 리뷰 개수 표시
- 별점 분포 차트 (5점: n개, 4점: n개, ...)
- 개별 리뷰 카드:
  * 작성자 이름
  * 별점
  * 작성일 (상대 시간 + 절대 시간)
  * 리뷰 텍스트
  * 첨부 이미지 (썸네일, 클릭 시 라이트박스로 확대)
  * 구매 인증 뱃지 (verified purchase)

### 4. 리뷰 필터링 및 정렬
- 정렬 옵션:
  * 최신순 (기본값)
  * 평점 높은순
  * 평점 낮은순
  * 도움이 된 순 (향후 확장)
- 필터링 옵션:
  * 별점별 필터 (5점만, 4점 이상 등)
  * 이미지 포함 리뷰만 보기
  * 구매 인증 리뷰만 보기

### 5. 페이지네이션
- "더보기" 버튼 방식 (Load More)
- 초기 로드: 5개 리뷰
- 더보기 클릭 시: 5개씩 추가 로드
- 무한 스크롤 대신 명시적 버튼 사용 (UX 베스트 프랙티스)

### 6. 리뷰 수정 및 삭제
- 본인이 작성한 리뷰만 수정/삭제 가능
- 수정 시 updatedAt 필드 업데이트
- 삭제 시 소프트 삭제 또는 하드 삭제 (비즈니스 정책에 따라)

## 데이터베이스 스키마 (이미 구현됨)
```prisma
model Review {
  id        String   @id @default(cuid())
  userId    String
  user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  productId String
  product   Product  @relation(fields: [productId], references: [id], onDelete: Cascade)
  rating    Int      // 1-5
  comment   String?  @db.Text
  images    String[] // 리뷰 이미지 URLs
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([userId])
  @@index([productId])
  @@index([rating])
  @@map("reviews")
}
```

## API 엔드포인트

### GET /api/products/[id]/reviews
- 특정 제품의 리뷰 목록 조회
- 쿼리 파라미터:
  * limit: 페이지당 개수 (기본값: 5)
  * offset: 시작 위치 (기본값: 0)
  * sort: 정렬 방식 (latest, highest, lowest)
  * rating: 별점 필터 (1-5)
  * withImages: 이미지 포함 리뷰만 (boolean)
- 응답: 리뷰 목록, 총 개수, 평균 별점, 별점 분포

### POST /api/products/[id]/reviews
- 새 리뷰 작성
- 인증 필요
- 구매 검증 필요
- Body: rating, comment, images[]
- 응답: 생성된 리뷰 객체

### PUT /api/reviews/[id]
- 리뷰 수정
- 인증 및 본인 확인 필요
- Body: rating, comment, images[]
- 응답: 업데이트된 리뷰 객체

### DELETE /api/reviews/[id]
- 리뷰 삭제
- 인증 및 본인 확인 필요
- 응답: 성공 메시지

### POST /api/upload/review-images
- 리뷰 이미지 업로드
- 인증 필요
- Multipart/form-data
- 파일 검증 및 최적화
- 응답: 업로드된 이미지 URL 배열

## 보안 및 검증

1. **구매 검증**: 해당 사용자가 제품을 실제로 구매했는지 Order 테이블에서 확인
2. **중복 방지**: userId + productId의 unique constraint 또는 애플리케이션 레벨 체크
3. **파일 업로드 보안**:
   - 파일 타입 검증 (MIME type + 확장자)
   - 파일 크기 제한
   - 파일명 sanitization
   - 안티바이러스 스캔 (선택)
4. **XSS 방지**: 리뷰 텍스트 sanitization
5. **Rate Limiting**: 리뷰 작성 빈도 제한 (예: 시간당 3개)

## 성능 최적화

1. 리뷰 작성률: 구매자 대비 리뷰 작성 비율
2. 이미지 첨부율: 전체 리뷰 중 이미지 포함 비율
3. 평균 리뷰 길이: 텍스트 품질 지표
4. 리뷰 조회율: 제품 상세 페이지 방문자 대비 리뷰 섹션 조회
5. 전환율 영향: 리뷰 시스템 도입 전후 비교

## 우선순위

### Phase 1 (MVP - 필수)

2. 리뷰 목록 표시
3. 기본 API 엔드포인트

### Phase 2 (중요)

2. 리뷰 수정/삭제

4. 페이지네이션

### Phase 3 (선택)

4. 성능 최적화

## 기술 스택

- Frontend: React 18, Next.js 14 App Router
- Backend: Next.js API Routes
- Database: PostgreSQL + Prisma ORM
- File Storage: 로컬 public 폴더 또는 AWS S3/Cloudinary
- Image Processing: Sharp 또는 Next.js Image Optimization
- Authentication: NextAuth v5
- UI Components: Tailwind CSS + Headless UI
- Form Handling: React Hook Form + Zod validation
- State Management: React useState/useReducer (서버 상태는 필요 시 React Query)
