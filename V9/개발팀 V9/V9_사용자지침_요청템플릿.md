## 0. 모든 템플릿의 공통 머리말 (필수 4필드)

모든 요청은 이 4줄로 시작한다. 도구·subagent가 자동 분기할 수 있게 하기 위한 키.

```
TYPE: <PRD | FEATURE | IDEA | BUGFIX | ENHANCE | DESIGN_NEW | DESIGN_FIX | REFACTOR | PERF | SECURITY | MIGRATION | DOCS | TEST | RESEARCH | INCIDENT>
SCOPE: <플랫폼 클러스터: web|mobile|desktop|wearable|xr|all 중 N개>
PRIORITY: <P0|P1|P2|P3>
TARGET_DATE: <YYYY-MM-DD 또는 "ASAP"|"unscheduled">
```

도구는 이 머리말을 읽고 해당 §의 본문 템플릿을 기대한다.

---

## 1. 요청 타입 14종 (어떤 템플릿을 쓰면 되는지)

| TYPE | 언제 쓰나 | 주 페르소나(받는 쪽) | 가는 도구 |
|---|---|---|---|
| PRD | 새 제품·큰 기능 정의 | 기획 + PM | Claude Code |
| FEATURE | 정의된 기능 1개 구현 | 개발 + QA | claude-code 또는 codex |
| IDEA | 탐색·발산 단계 | 비판평가 + 시뮬레이션 | Claude Code |
| BUGFIX | 버그 보고 → 수정 | 개발 + QA + SRE | claude-code |
| ENHANCE | 작은 개선·UX 보강 | 디자인 + 개발 | either |
| DESIGN_NEW | 신규 디자인 의뢰 | 디자인 + 기획 | Claude Code(Figma MCP) |
| DESIGN_FIX | 기존 디자인 수정 | 디자인 | claude-code |
| REFACTOR | 동작 변경 없이 구조 개선 | 개발 + 비판평가 | codex(병렬) |
| PERF | 성능 최적화 | 개발 + SRE | claude-code |
| SECURITY | 취약점·보안 강화 | Trust&Safety + SRE | claude-code(로컬) |
| MIGRATION | DB·API·플랫폼 마이그레이션 | DataOps + 개발 | claude-code |
| DOCS | 문서 작성·갱신 | 모든 팀 | codex |
| TEST | 테스트 추가·보강 | QA | codex(병렬) |
| RESEARCH | 의사결정용 조사 | 비판평가 + 기획 | claude-code |
| INCIDENT | 장애 대응 | SRE + Trust&Safety | claude-code |

## 5. "그냥 자유 서술로 보내고 싶을 때"

4필드 머리말만 채우고 본문은 자유 서술. 도구가 다음 순서로 처리:
1. 머리말 TYPE 보고 해당 템플릿 빈칸을 자동 추출
2. 누락된 필드는 질문 1-3개로 보충
3. 보충 답변을 받아 정식 템플릿으로 변환 후 실행

이 모드는 IDEA·BUGFIX·ENHANCE에서 효과 큼. PRD·MIGRATION·SECURITY는 자유 서술 비권장(빠진 필드가 위험).

## 7. 골든 케이스 시드는 모든 템플릿의 필수

위 14개 템플릿 모두 마지막 즈음에 **"골든 케이스 후보"** 또는 **"승격"** 항목이 있다.
이유: V7 본문 C1 — 사용자가 보낸 모든 요청은 잠재적 회귀 테스트. 통과 시 evals 자동 후보 등록 → 1-클릭 승인.

## 8. 안티패턴 (사용자 측)

1. 머리말 4필드 누락 → 도구가 잘못된 페르소나에 위임
2. PRD 본문에 "알아서 해줘" — 결정 누락 시 도구가 임의로 가정
3. BUGFIX에 재현 절차 누락 → 추측 코드 양산
4. DESIGN에 상태 매트릭스 누락 → empty/error 디자인 빠짐
5. SECURITY를 Codex로 보내 시크릿 노출 위험
6. REFACTOR 범위 미정의 → 무한 확장
7. 한 요청에 TYPE 2개 섞기 → 분리해서 두 번 보내라

## 9. 최소 시작 (오늘 바로 쓸 수 있도록)

가장 자주 쓰는 3개부터: **BUGFIX · FEATURE · DESIGN_FIX**.
나머지는 발생 시점에 본 문서 참조. 템플릿 빈칸 채우기가 익숙해지면 자유 서술 모드(§5)로 점진 전환.
