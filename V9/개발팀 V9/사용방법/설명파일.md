설치 모드 3가지

minimal — .claude/{agents,skills,hooks,evals,personas} + CLAUDE.md + 요청 템플릿 (5분, 한 프로젝트 시험용)
standard — 위 + .github/workflows/ 4개 + Codex(AGENTS.md, .codex/) + 모노레포 placeholder (15분, 정착용)
shared — 위 + ~/.claude/{agents,skills,hooks} symlink (30분, 여러 리포 공유)

핵심 적용 메커니즘

CLAUDE.md (≤200줄) — 프로젝트 루트, 진입점
.claude/settings.json — hook lifecycle(루프/안드로이드 포함) + 권한·금지
.claude/agents/*.md — frontmatter(name/description/tools/model) → /agents 로 호출
.claude/skills/<name>/SKILL.md — 자동 매칭 트리거
.claude/hooks/*.sh — preToolUse:Edit, prePR, onTaskComplete, onLoopTick/onLoopEnd 등 라이프사이클에 매핑 (settings.json에서 연결)
공유DB MCP — Docker Compose로 띄운 뒤 V7_API·V7_TOKEN 환경변수만 주입 (공유DB 인프라 V2 식별자)

검증은 자동
verify.sh가 항목(CLAUDE.md·settings JSON·agents 수(≥18)·skills(≥28)·hooks 실행권한(≥19)·evals(loop 포함)·요청 템플릿(T1~T18)·공유DB API 응답·CLAUDE.md 9섹션 키워드)을 점검.
첫 작업 권장 흐름
docs/request-templates/T4_BUGFIX.md 빈칸 채워서 보내기 → onTaskStart 훅이 공유DB에서 유사 사례 자동 주입 → code-explorer → critic-reviewer + test-architect 병렬 → preCommit/prePR 게이트 → onTaskComplete가 결과 DB 적재.
