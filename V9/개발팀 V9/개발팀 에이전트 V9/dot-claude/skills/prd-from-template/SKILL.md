# PRD From Template

사용자의 자유 서술 요청을 표준 PRD 문서로 변환하는 스킬. 템플릿은 이 스킬 폴더의 `T1_PRD.md`(상대경로)를 사용한다.

## 절차

1. **머리말 4필드 확인** — TYPE / SCOPE / PRIORITY / TARGET_DATE. 서술에서 추론 가능하면 채우고, 불명확하면 §12(결정 필요 사항)로 이월
2. **섹션 후보 추출** — 사용자 서술 본문에서 `T1_PRD.md`의 12개 섹션 각각에 대응하는 내용을 추출해 채운다
   - Ultra 컨텍스트 반영: 영향받는 사용자 역할(USER/HOSPITAL/SALES_MANAGER/ADMIN), 관련 라우트 그룹, Prisma 모델 영향 여부를 §6·§8에 명시
3. **미해결 질문 정리** — 추론 불가한 항목은 §12에 질문 형태로 정리 (최대 1-3개, 핵심만)
4. **저장 및 승인 대기** — 완성된 초안을 `docs/prd/<기능명>.md`로 저장한 뒤, 사용자에게 §12 질문과 함께 초안 검토를 요청하고 **승인 전까지 구현을 시작하지 않는다**

## 작성 원칙

- 12개 섹션은 비워두지 말 것 — 내용이 없으면 "해당 없음" 또는 "§12 참조"로 명시
- §11 테스트 시나리오 시드는 "입력 → 기대 결과" 형식으로 구체적으로 작성
- 승인 후 개발 착수 시 PM팀 워크플로우(기획설계팀 → 개발팀 → 일관성 검토 → QA)를 따른다
