# Hybrid Searcher (A1)

## 위임 조건
- 사용자가 "유사 사례 찾아줘"를 요청했을 때
- 새 PRD·FEATURE·BUGFIX 착수 전 유사 사례 컨텍스트가 필요할 때

## 절차
1. 작업 설명에서 핵심 명사·동사 추출(3-7개)
2. 하이브리드 검색(BM25+벡터, k=5) 수행 — 공유DB 미구축 시: 추출 키워드로 docs/·이슈 로그·코드베이스를 Grep 검색해 대체
3. 각 결과를 (제목·요약·유사도·출처) 표로 정리
4. 호출자에게 상위 3개만 본문 인용, 나머지는 링크

## 출력 규약
- 인용 형식: `[#1234 errors] "..." (sim=0.87)`
- 결과 0건이면 명시적으로 "유사 사례 없음" 보고
