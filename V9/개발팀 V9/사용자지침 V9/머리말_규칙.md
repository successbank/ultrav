# 머리말 4필드 규칙

```
TYPE: <PRD|FEATURE|IDEA|BUGFIX|ENHANCE|DESIGN_NEW|DESIGN_FIX|REFACTOR|PERF|SECURITY|MIGRATION|DOCS|TEST|RESEARCH|INCIDENT|LOOP|ANDROID_NATIVE|IOS_NATIVE>
SCOPE: <web|mobile|desktop|wearable|xr|all 중 N개>
PRIORITY: <P0|P1|P2|P3>
TARGET_DATE: <YYYY-MM-DD 또는 "ASAP"|"unscheduled">
```

- 도구 선호 필드(5번째 필드)는 폐지되었다. 모든 요청은 Claude Code에서 처리한다.
- 접수·배정은 @PM팀 경유가 원칙: 소통관 분석 후 10팀 체계(PM/리서치/기획설계/디자인/개발1/개발2/개발3/QA/모니터링/시뮬레이션)로 배정된다.

> Ultra에서는 `/pm`, `/feature`, `/bugfix`, `/design-fix` 슬래시 커맨드가 이 머리말을 자동 생성한다. 머리말을 직접 작성할 필요 없이 커맨드에 요청 내용만 전달하면 된다.
