# 모델 라우팅 정책 (V9 / A2 계승)

## 기본 매트릭스
| 작업 | Claude | OpenAI |
|---|---|---|
| 단순 자동완성/포매팅 | Haiku-4-5 | GPT-5-mini |
| 일반 코드/리뷰 | Sonnet-4-6 | GPT-5 |

| 긴 컨텍스트 탐색 | Sonnet long-context | GPT-5 large |

## V9 신규 에이전트 라우팅 (루프·안드로이드)
| 에이전트 | 역할 | Claude | 근거 |
|---|---|---|---|
| `loop-orchestrator` | 6요소 loop spec 변환·fan-out·tick 관리 | **Opus-4-6** | 다단계 계획·조율(critical) |
| `loop-grader` | tick/결과 루브릭 채점, revise 판정 | **Sonnet-4-6** | 일반 코드·리뷰 등급 판정 |
| `loop-budget-guard` | 토큰·비용·반복·시간 상한 결정적 집행 | **Haiku-4-5** | 단순 비교·차단 판정 |
| `android-native-builder` | Kotlin/Compose/Gradle 빌드·lint·test 반복 | **Sonnet-4-6** | 일반 코드/빌드, native_api·gradle_graph·play_policy 시 escalate |

## 페르소나 메타 예
```yaml
model_policy:
  default: haiku-4-5
  escalate_on: [code_review, design_review, security_audit]
  critical: opus-4-6
```

## 비용 관리
- usage_tracking에 항상 기록
- FinOps 일/월 한도 → 70/85/100% 알람
- 일 한도 90% 초과 시 critical 외 강제 다운그레이드
