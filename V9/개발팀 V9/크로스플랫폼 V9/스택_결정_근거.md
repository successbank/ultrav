# 스택 결정 근거

| 분야 | 선택 | 이유 |
|---|---|---|
| Mobile | RN 0.76 + Expo SDK 52 | TS 생태 공유, EAS 안정성 |
| 모바일 네이티브(선택) | Android=Kotlin/Compose · iOS=Swift/SwiftUI | 하드웨어·온디바이스AI·플랫폼표준 UI는 네이티브(RN 병행) |
| Web | React 19 + Vite + TanStack | 동일 React, 빠름 |
| Desktop | Tauri 2 | 번들 작고 OS 통합 우수 |
| Wearable | 네이티브 (SwiftUI / Compose-Wear) | RN 미지원/불안정 |
| XR | 카테고리별 분리 (SwiftUI+RealityKit / Compose-XR / Unity OpenXR / 페어 폰 RN) | 카테고리 격차 큼 |
